# idv_map_guides

IdentityV Cryptic Notes maps.

## Features

1. 全难度地图数据
- 厄运之女
- [x] 新手
- [x] 简单（部分结构仍需校对）
- [ ] 普通
- [x] 困难（部分结构仍需校对）
- [x] 噩梦
- [ ] 宝藏房刷点
- 磷光症
- [ ] 普通
- [ ] 困难
- [x] 噩梦（部分结构仍需校对）
- [ ] 宝藏房刷点

2. 根据入口分类选择地图
- 厄运之女
- [x] 正门
- [x] 一楼侧门
- [x] 二楼侧门
- 磷光症
- [x] B1层左转进口
- [x] B1层右转进口
- [x] B2层三叉轨道

3. 单人导航
- [x] 单人全必刷点导航
- [x] 单人全必刷点导航（带书）（在导航设置中关闭“导航至出口结束”）
- [x] 任意点导航至出口（在导航设置中清空资源点，并选择起点）
- [x] 单人噩梦不打夜莺（在导航设置中关闭“优先抵达缪斯房”）
- [ ] 单人全可能刷点导航
- [ ] 单人全可能刷点导航（带书）

4. 双人导航
- [x] 双人全必刷点导航
- [x] 双人噩梦不打夜莺
- [ ] 双人全可能刷点导航

5. 特殊导航条件
- [ ] 不走难跳的地方（包括磷光症地图中磁石崩塌的地方）
- [x] 厄运之女走出入口（在正门/侧门间移动）

6. 高级导航设置
- [x] 按地图独立调整单人/双人各阶段权重
- [x] 各地图导航参数互相隔离

7. 查看其他相似地图
- [x] 入口缩略图一致地图
- [ ] 全地图结构相似
