# idv_map_guides

IdentityV Cryptic Notes maps.

## Features

1. 全难度地图数据
- [x] 新手
- [ ] 简单
- [ ] 普通
- [x] 困难（部分结构仍需校对）
- [x] 噩梦（部分结构仍需校对）

2. 根据入口分类选择地图
- [x] 正门
- [x] 一楼侧门
- [x] 二楼侧门

3. 单人导航
- [x] 单人全必刷点导航
- [x] 单人全必刷点导航（带书）（在导航设置中关闭“导航至出口结束”）
- [x] 任意点导航至出口（在导航设置中清空资源点，并选择起点）
- [x] 单人噩梦不打夜莺（在导航设置中关闭“优先抵达缪斯房”）
- [ ] 单人全可能刷点导航
- [ ] 单人全可能刷点导航（带书）

4. 双人导航
- [x] 双人全必刷点导航
- [x] 双人噩梦不打夜莺
- [ ] 双人全可能刷点导航

5. 查看其他相似地图
- [x] 入口缩略图一致地图
- [ ] 全地图结构相似
