# idv_map_guides

IdentityV Cryptic Notes maps.

## Features

1. 全难度地图数据
- [x] 新手
- [ ] 简单
- [ ] 普通
- [x] 困难
- [x] 噩梦

2. 选择地图，支持根据入口分类
- [x] 正门
- [x] 一楼侧门
- [x] 二楼侧门

3. 导航
- [x] 单人全必刷点导航
- [x] 单人全必刷点导航（带书）（在导航设置中关闭`导航至出口结束`）
- [x] 任意点导航至出口（在导航设置中清空资源点，并选择起点）
- [ ] 单人噩梦不打夜莺导航
- [ ] 双人全必刷点导航
- [ ] 双人噩梦不打夜莺导航
